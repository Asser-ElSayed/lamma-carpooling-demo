# Planning authority

The implementation follows the approved Lamma Backend Planning v1.1 baseline of 8 November 2026. The original planning files are maintained separately and are not included in the current repository. Decisions D-01–D-08 govern the executable: immediate one-seat confirmation, ordered-node matching, development JWTs, feature-grouped Minimal APIs, fixed three-seat rides and Rider-scoped idempotency. Cancellation and advanced product features remain deferred.

Implementation defaults and rationale are recorded in [ADRs](../decisions/ADR-001-feature-first-monolith.md). [Validation](../validation.md) maps the implementation to AC-01–AC-10. [Reviewer walkthrough](../demo-walkthrough.md) supplies the demo sequence.
